The following backend items were not in the original Sprint 3 backlog but are being delivered in Sprint 3 as they are critical path dependencies for Sprint 4. They are formally tracked here as additional scope.
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
  \item \textbf{GitHub Webhook HMAC hardening} — \texttt{X-Hub-Signature-256} validation; BackgroundTask inference to prevent GitHub timeout
  \item \textbf{Automated PR comment posting} — \texttt{post\_github\_comment} helper using \texttt{urllib}; auto-triggered after prediction
  \item \textbf{Dynamic OAuth token system} — \texttt{integrations} PostgreSQL table; \texttt{POST /api/integrations/github/webhook} endpoint; per-repo token storage replacing global \texttt{.env} token
  \item \textbf{Frontend data endpoint} — \texttt{GET /api/predictions} with descending chronological ordering
\end{itemize}
These items are formally documented in the Sprint 3 Completion Report as unplanned scope.

\section{Definition of Done (Sprint 3)}

A Sprint 3 item is \textbf{Done} when:
\begin{enumerate}[leftmargin=1.8em, itemsep=2pt]
  \item All acceptance criteria verified and signed off by item owner.
  \item Code merged to \texttt{main} via a reviewed GitHub pull request.
  \item Relevant Vitest unit tests written and passing (\texttt{vitest run}).
  \item No new ESLint errors introduced (\texttt{eslint src/}).
  \item Feature renders correctly in the running Vite dev server (\texttt{localhost:5173}).
  \item Impacted documentation updated (README or codebase map).
  \item Item marked Done on the Agile project board.
\end{enumerate}
