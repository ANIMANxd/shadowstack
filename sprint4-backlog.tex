PBI-061 \New{} &
GitHub OAuth Login &
As a user, I want to log in to ShadowStack via my GitHub account so that my repositories and tokens are securely managed. &
\texttt{/login} page with GitHub OAuth button; redirects to GitHub with \texttt{repo} + \texttt{admin:repo\_hook} scopes; \texttt{POST /api/auth/github} exchanges code for token; token stored; \texttt{/callback} page handles redirect; protected routes redirect unauthenticated users to \texttt{/login} &
HIGH & 5 \\ \hline

\rowcolor{newbg}
PBI-062 \New{} &
Settings Page / Repo Connect UI &
As an authenticated user, I want a settings page where I can connect my GitHub repository so that ShadowStack can analyse my PRs. &
\texttt{/settings} page with \texttt{owner/repo} text field and Connect button; button calls \texttt{POST /api/integrations/github/webhook} with repo + token; success/error feedback shown; connected repos listed &
HIGH & 3 \\ \hline

\rowcolor{newbg}
PBI-063 \New{} &
Wire Dashboard to Real Predictions Data &
As a user, I want the dashboard charts to show real PR analysis results from my connected repository so that I can see actual cost predictions. &
\texttt{useDashboardData.ts} passes connected repo as filter; \texttt{GET /api/predictions?repo=owner/repo} returns scoped data; grouped bar chart shows one bar per PR analysis; \texttt{mockAdapter} only activates when API is truly unreachable &
HIGH & 2 \\ \hline

\section{Definition of Done (Sprint 4)}

A Sprint 4 item is \textbf{Done} when:
\begin{enumerate}[leftmargin=1.8em, itemsep=2pt]
  \item All acceptance criteria verified and signed off by item owner.
  \item Code merged to \texttt{main} via a reviewed GitHub pull request.
  \item Relevant unit/integration tests written and passing in CI.
  \item No new ESLint (frontend) or Pylint (backend) errors introduced.
  \item Feature demonstrated in the running Docker Compose environment.
  \item Impacted documentation updated (README, API docs, or user guide).
  \item Item marked Done on the Agile project board.
\end{enumerate}
